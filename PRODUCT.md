# ASCII STUDIO
A Chinese, browser-local image-to-ASCII working surface. Primary workflow: import an image, adjust character density and rendering, inspect, export. The supplied video is the visual reference. Preserve image privacy; no network upload or persistence. Single responsive page, no account or backend processing.

Support GIF sources and deterministic looping effects for still images. Users control playback, seek, speed, strength, frame rate and applicable loop duration/direction, then export a GIF or the current still frame. Decode and encode locally with bounded memory and cancellable progress. Do not silently flatten unsupported animated image formats.
