# ASCII STUDIO design
Operate mode. Reference-pinned pale silver workspace with restrained blue accents, compact tool panels surrounding the character artwork. Chinese system UI typography, monospace only for brand, characters and measurement. Preview is the dominant surface; inputs and presets are immediately available. Desktop three columns, tablet upload strip over preview/settings, phone stacked upload-preview-settings. All controls have keyboard focus, native semantics and reduced-motion support. Actual characters are rendered from image luminance using Canvas, not a decorative simulation.

Animation belongs to the generated artwork, not the surrounding interface. GIF playback and generated effects share a scrubber under the preview. Motion controls remain in the adjustment panel and only show applicable options. Frame rate, cached image data and export size are bounded; export has progress and cancellation. Keep still-image empty state and original presets intact.
